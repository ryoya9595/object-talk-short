AIショート動画 ・ object talk

モノが喋る動画を、
15分で1本。

カイロやレモンが、ピクサー映画みたいな顔で豆知識を喋るショート動画。撮影も顔出しもいりません。AIを4つ順番に使うだけで、手を動かすのは5分ほど。残りは生成を待つ時間です。

1台本を作る
2画像を作る
3声を作る
4喋らせる
▍ 9:16 ショート
振るだけで

AIを4つ、バトンのようにつなぐ。

1つのAIで全部やるのではなく、得意なAIに1工程ずつ任せます。前の工程で作ったものを、次のAIに渡していくだけです。

① 台本

ChatGPT

カスタムGPT「Object Talk」にモノの名前を入れると、画像の指示文と10秒台本が出る。

② 画像

Nano Banana Pro

①の指示文を貼るだけで、顔と手のついたキャラ画像ができる。縦長9:16で。

③ 声

DeeVid AI

①の台本を読み上げさせる。アニメ声優のような声を選び、1.3倍速に。

④ 動画

Kling AIアバター

②の画像と③の声を入れると、口の動きが声に合った動画になる。

必要なのは各AIの無料アカウントだけ — どのAIも無料枠で試せます（使いすぎるとクレジットが足りなくなることはあります）。すべてブラウザで使えるので、インストールは要りません。

作り方

プロンプトはボタンでコピーできます。「カイロ」の部分を、作りたいモノに変えて使ってください。

1
台本と画像の指示文を作るChatGPT
  1. ChatGPTの左メニューから 「GPT」（GPTの詳細を見る）を開く
  2. 「GPTを検索する」に英語で Object Talk と入れる
  3. 作成者が aicenturies.com のものを選んで「チャットを開始する」
  4. 作りたいモノの名前だけを送る（例：使い捨てカイロ）

「Text-to-Image Prompt（画像の指示文）」と「10-Second Script（10秒台本）」が出てきます。関連するモノの案もいくつか出るので、ネタ切れしません。

使い捨てカイロ
台本は日本語で、10秒で読める長さにしてください。
台本が英語で出てきたときは、2行目を足して送ります。
2
キャラクターの画像を作るGemini / Genspark
  1. ①の画像の指示文（英語のかたまり）を 1文字も変えずに コピー
  2. Geminiならそのまま貼って送る。Gensparkなら「AI画像」→ モデル Nano Banana Pro → 比率 9:16 を選んでから貼る
  3. できた画像をダウンロード
次のプロンプトで画像を生成してください。縦長（アスペクト比 9:16）で。

（ここに①の画像の指示文を貼る）

Geminiで作ると、右下に薄いGeminiのマーク（透かし）が入ります。気になる人はGensparkで作ると入りません。

3
台本を読み上げる声を作るDeeVid AI
  1. DeeVid AIに無料登録して、「テキスト読み上げ」 を開く
  2. ①の10秒台本をそのまま貼る
  3. 「音声」の言語を 日本語 にして（最初は英語になっています）、好きな声を選ぶ
  4. 速度を 1.0 → 1.3 にして「作成」→ ダウンロード

ゆっくり喋るとスワイプされるので、少し早口にするのがコツです。30秒ほどでできます。

4
画像と声を合わせて喋らせるKling
  1. Klingで 「AIアバター 2.0」（Avatar 2.0）を開く
  2. 「画像をアップロード」に②の画像、「音声をアップロード」に③の声を入れる
  3. 下のプロンプトを貼って「生成」
キャラクターは表情豊かに、手を使ったボディランゲージも含めて動かして。
背景は自然に動かして。
テロップは不要。

生成には5〜10分かかります。待っている間に次のネタの①〜③を進めておくと早いです。

④のプロンプトは空欄にしない — 何も入れないと、口しか動かない・知らない文字のテロップが勝手に出る、という動画になりがちです。上の3行を入れるだけで、身振りつきで喋るようになります。

Gemini Proなら、声と動画を1回で。

Googleの有料プラン（Gemini Pro）を使っている人は、③と④をまとめてGeminiに頼めます。声を作ってアップロードする手間が省けます。

画像ができたら、同じチャットにそのまま下の文を送ります。「セリフ」の部分に①の台本を入れてください。

この画像をそのまま使って、縦長（9:16）の動画にしてください。カイロのキャラクターがカメラに向かって、日本語で次のセリフを話します。

・声：アニメ声優のような、元気で少し怒っている男性の声。テンポは少し速め

違い — 声の種類や速さを細かく選べるのは④のKlingルート。手軽さはGeminiルート。Geminiの動画は1本8秒ほどなので、台本は短めにします。

作れるのと、伸びるのは別。

ここまでで「喋る動画」は作れます。ただ、SNSで流れてくるバズ動画は、作者が1本に4時間かけていることもあります。差が出るのはこの4つです。

差が出るところこうする
ネタ「へえ」と言いたくなる豆知識か。身近なモノの“間違った使い方”を本人（モノ）に怒らせる形は強い。例：カイロ「揉まないで、振るだけでいい」
最初の1秒台本の1文目を、ツッコミや命令から始める。「おいおい」「密閉しないで！」
画像の表情気に入る顔が出るまで②を何回か作り直す。台本の感情（怒り・困り・得意げ）と表情を合わせる
字幕AIにはテロップを入れさせず、できた動画にCapCut等で自分で入れる。音なしで見る人にも伝わる

気をつけること

投稿する前に、ここだけ確認してください。

✓台本の豆知識が正しいか、自分で一度調べる（AIの台本は間違えることがある）
✓投稿するときは、SNSの「AI生成」ラベルをつける
✓使ったAIの利用規約で、商用利用がOKか確認する
✓画像の中に変な文字や崩れた指がないか見る
✕実在する商品のロゴやパッケージをそっくり描かせる
✕他の人のバズ動画の台本や声を、そのまま真似する

よくある質問

全部このAIじゃないとダメ？
いいえ。画像・声・動画のAIは他のものに替えても作れます。大事なのは「台本 → 画像 → 声 → 喋らせる」の順番です。

1本の長さは？
10秒前後が作りやすいです。長くしたいときは、同じキャラの画像で台本を2〜3本に分けて作り、あとでつなげます。

毎回同じキャラで続けたい
最初に作った画像を保存しておき、④で毎回それを使います。①で出た指示文も保存しておくと、似た画像を作り直せます。

スマホだけで作れる？
どのAIもスマホのブラウザで開けますが、ファイルのダウンロードとアップロードが多いので、パソコンの方が楽です。
